# ALS — Issue Tracker

This is the public issue tracker for **ALS (Advanced Looping Station)**, a sequenced looper for live performance that runs on macOS and Linux. To learn more about ALS, read the documentation or get the app, visit [als-looper.com](https://www.als-looper.com/).

It holds **no source code and no downloads**. Use it only to report bugs and suggest features.

## Before you open an issue

- Search the [existing issues](../../issues?q=is%3Aissue), open and closed. If your problem or idea is already there, add a 👍 or a comment with new details instead of opening a duplicate.
- Open one issue per bug or idea. Separate reports are easier to track and close.

## Report a bug

Open a [new issue](../../issues/new/choose) and pick **Bug report**. The most useful reports include:

- **ALS version** and **operating system** (macOS or Linux, with its version).
- **Audio setup:** the audio interface or device, sample rate and buffer size (shown in the footer), and on Linux whether you use JACK or PipeWire.
- **Plugins involved**, if any: name, vendor, format (VST3 or CLAP) and version.
- **Steps to reproduce**, starting from a new project if you can, and what you expected to happen instead.
- Screenshots or a short screen recording. If a specific project triggers the problem, you can attach its `.als` file (it holds no recordings, only the arrangement and settings, but it does contain the paths of any audio clips you dropped in).

## Suggest a feature

Open a [new issue](../../issues/new/choose) and pick **Feature request**. Start from the problem: describe what you are trying to do on stage or while preparing a performance, and what makes it hard today. A proposed solution is welcome, but the use case matters most.

Feature requests are read and discussed, but they are not a commitment to ship.

## Please don't

- Post license keys, passwords, personal data or private file paths. Check screenshots and attached files before uploading them.
- Disclose **security vulnerabilities** in a public issue. Report them privately to [rosati.matteo@gmail.com](mailto:rosati.matteo@gmail.com) instead.
- Use this tracker for purchases, licensing or billing questions: it is not a support channel.
